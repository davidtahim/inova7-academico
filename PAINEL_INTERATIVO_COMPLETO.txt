🔄 FLUXO DO PROFESSOR:
══════════════════════════════════════════════════════════════════════════════

   1️⃣  ACESSA
   └─→ Planejamento → Professores → 📅 (seu professor)

   2️⃣  VÊ A TABELA
   └─→ Todos os horários (Seg-Sex, Manhã-Noite)

   3️⃣  CLICA NOS HORÁRIOS
   └─→ 1º clique: CINZA → VERDE (Preferido)
   └─→ 2º clique: VERDE → AZUL (Disponível)
   └─→ 3º clique: AZUL → CINZA (Indisponível)
   └─→ Pode clicar quantas vezes quiser

   4️⃣  VÊ RESUMO ATUALIZAR
   └─→ Números mudam em tempo real
   └─→ Sem recarregar a página

   5️⃣  CLICA "💾 SALVAR"
   └─→ Envia os dados
   └─→ Mostra "⏳ Salvando..."

   6️⃣  VÊ SUCESSO
   └─→ "✓ Sucesso! Sua disponibilidade foi salva."
   └─→ Página recarrega

   7️⃣  DADOS SALVOS
   └─→ Pode fazer logout
   └─→ Fazer login de novo
   └─→ Seus dados continuam lá! ✓


🔄 FLUXO DO COORDENADOR:
══════════════════════════════════════════════════════════════════════════════

   Same as professor, but:
   - Coordenador consegue acessar de QUALQUER professor
   - Pode editar a disponibilidade de qualquer um
   - Admin e Staff têm o mesmo acesso


🎨 AS CORES SIGNIFICAM:
══════════════════════════════════════════════════════════════════════════════

   🟢 VERDE = Preferido
      └─ Horário ideal para lecionar
      └─ Primeira prioridade do professor

   🔵 AZUL = Disponível
      └─ Pode lecionar, mas não é preferencial
      └─ Segunda opção

   ⚪ CINZA = Indisponível
      └─ Não pode lecionar neste horário
      └─ Conflito, compromisso, etc.

📊 DADOS QUE VOCÊ VAI EDITAR:
══════════════════════════════════════════════════════════════════════════════

   professor_availabilities (Tabela do Banco)
   
   Colunas:
   - professor_id: Qual professor
   - academic_term_id: Qual semestre
   - weekday: Qual dia (1=Seg, 2=Ter, 3=Qua, 4=Qui, 5=Sex)
   - starts_at: Horário início (HH:MM, ex: 07:30)
   - ends_at: Horário fim (HH:MM, ex: 08:20)
   - preference: Tipo (preferred / available / unavailable)
   - created_at / updated_at: Timestamps

🔄 FLUXO DE DADOS:
══════════════════════════════════════════════════════════════════════════════

   PROFESSOR CLICA
        ↓
   JavaScript atualiza célula
        ↓
   Muda classe CSS (bg-success/bg-info/bg-light)
        ↓
   updateSummary() recalcula totais
        ↓
   Professor vê mudanças em tempo real
        ↓
   Professor clica "Salvar"
        ↓
   JavaScript coleta todos os slots selecionados
        ↓
   Converte para JSON
        ↓
   Envia via fetch() com CSRF token
        ↓
   Laravel recebe no updateAvailability()
        ↓
   Valida permissão com checkAccess()
        ↓
   Valida dados com $request->validate()
        ↓
   DELETE todas as disponibilidades antigas
        ↓
   INSERT todas as novas disponibilidades
        ↓
   Retorna JSON sucesso
        ↓
   JavaScript mostra "✓ Sucesso!"
        ↓
   Recarrega página automaticamente
        ↓
   Professor vê seus dados salvos ✓

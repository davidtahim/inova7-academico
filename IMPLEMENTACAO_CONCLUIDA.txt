OBJETIVO:
Permitir que administradores, coordenadores e staff gerenciem quais disciplinas
cada professor está qualificado para lecionar (Ex: Prof. Reginaldo com 8 disciplinas).

================================================================================
ARQUIVOS IMPLEMENTADOS:
================================================================================

1. CONTROLLER ATUALIZADO:
   📄 app/Http/Controllers/ProfessorAvailabilityController.php
   - Adicionado: showSubjects() - Exibe interface de seleção
   - Adicionado: updateSubjects() - Salva disciplinas selecionadas
   - Importado: Subject model e Request

2. ROTAS ADICIONADAS:
   📄 routes/web.php
   - GET  /admin/planejamento/professores/{professor}/disciplinas
     Nome: admin.professors.subjects
   - PUT  /admin/planejamento/professores/{professor}/disciplinas
     Nome: admin.professors.update-subjects

3. VIEWS CRIADAS:
   📄 resources/views/admin/professors-subjects.blade.php (NOVA)
   - Exibe disciplinas selecionadas do professor
   - Formulário com checkboxes para todas as disciplinas
   - Resumo com estatísticas (total, habilitado, não habilitado)
   - Botões Salvar/Cancelar

4. VIEWS ATUALIZADAS:
   📄 resources/views/admin/professors/index.blade.php
   - Adicionado botão 📚 (livros) para acessar painel de disciplinas
   - Localizado ao lado do botão 📅 (disponibilidade)

5. SEEDER CRIADO:
   📄 database/seeders/ProfessorSubjectsSeeder.php (NOVA)
   - Associa 8 disciplinas ao professor Reginaldo Borba
   - Busca professor por nome
   - Busca disciplinas por código/nome
   - Sincroniza via sync()
   - Feedback informativo no console

6. MODELOS (CONFIRMADOS):
   - Professor::subjects() belongsToMany(Subject) ✅
   - Subject::professors() belongsToMany(Subject) ✅
   - Tabela pivot: professor_subject ✅

COMO USAR (RESUMIDO):
================================================================================

1. PREPARAR DADOS:
   cd /seu/dominio
   php artisan tinker
   
   # Dentro do tinker:
   App\Models\Professor::where('name', 'like', '%Reginaldo%')->first();
   
   # Se não existir, criar:
   App\Models\Professor::create([
       'registration' => 'UNI727777',
       'name' => 'Reginaldo Borba',
       'email' => 'reginaldo@inova7.local',
       'qualification' => 'Mestre',
       'active' => true
   ]);
   exit;

2. EXECUTAR SEEDER:
   php artisan db:seed --class=ProfessorSubjectsSeeder

3. ACESSAR PAINEL:
   - Login como admin/coordenador/staff
   - Planejamento → Professores
   - Clique no botão 📚 (Reginaldo)
   - Marque/desmarque disciplinas
   - Clique "Salvar Disciplinas"

        ↓

        ↓

  - Valida subject_ids[]

🚀 COMO USAR:
══════════════════════════════════════════════════════════════════════════════

   PARA PROFESSOR:
   ───────────────
   1. Login como professor (role = 'teacher')
   2. Vai para: Perfil → Minha Disponibilidade
   3. Marque os horários que você prefere lecionar
   4. Cores:
      - Verde = Prefiro (preferred)
      - Azul = Disponível (available)
      - Cinza = Indisponível (unavailable)
   5. Clique "Salvar Minha Disponibilidade"
   6. ✓ Suas preferências foram registradas!

   PARA COORDENADOR:
   ─────────────────
   1. Login como coordenador
   2. Vai para: Planejamento → Professores
   3. Clique no botão 📅 (calendário) de um professor
   4. Veja/Edite a disponibilidade daquele professor
   5. Clique "Salvar Disponibilidade"
   6. ✓ Disponibilidade do professor foi atualizada!

   PARA ADMIN:
   ───────────
   Mesmo que coordenador, com acesso a qualquer um

💾 CONFIGURAÇÃO DE BANCO:
══════════════════════════════════════════════════════════════════════════════

   Se a coluna `professor_id` não existe em `users`, execute:

   SQL:
   ────
   ALTER TABLE users ADD COLUMN professor_id BIGINT UNSIGNED NULL;
   ALTER TABLE users ADD FOREIGN KEY (professor_id) 
       REFERENCES professors(id) ON DELETE SET NULL;

   Depois, vincule usuários existentes (via tinker ou SQL):

   PHP:
   ────
   php artisan tinker

   $professores = App\Models\Professor::all();
   foreach ($professores as $prof) {
       $user = App\Models\User::where('email', $prof->email)->first();
       if ($user && $user->role === 'teacher') {
           $user->professor_id = $prof->id;
           $user->save();
       }
   }

   exit;

🔍 ERROS POSSÍVEIS E SOLUÇÕES:
══════════════════════════════════════════════════════════════════════════════

   ERRO 1: "405 Method Not Allowed"
   ├─ Significado: Rota não está como PUT
   ├─ Solução: Verifique routes/web.php linha 42
   └─ Deve ser: Route::put(...)

   ERRO 2: "403 Forbidden"
   ├─ Significado: Sem permissão
   ├─ Solução: Executar no SSH:
   │   php artisan tinker
   │   $user = App\Models\User::find(1);
   │   $user->professor_id = {numero_do_professor};
   │   $user->save();
   │   exit;
   └─ Usuário precisa estar vinculado ao Professor

   ERRO 3: "500 Internal Server Error"
   ├─ Significado: Erro no servidor
   ├─ Solução: Ver logs
   │   tail -f storage/logs/laravel.log
   └─ Clique em Salvar de novo para ver o erro

   ERRO 4: "Network Error" ou "Failed to fetch"
   ├─ Significado: Problema de conexão ou CORS
   ├─ Solução: Limpar cache
   │   php artisan cache:clear
   │   php artisan route:clear
   └─ Recarregue a página

🛠️ SE NÃO FUNCIONAR:
══════════════════════════════════════════════════════════════════════════════

   OPÇÃO A: Limpar tudo e tentar de novo
   
   No SSH do servidor:
   
   php artisan config:clear
   php artisan cache:clear
   php artisan route:clear
   
   # Se usar nginx:
   sudo systemctl restart nginx
   
   # Se usar apache:
   sudo systemctl restart apache2
   
   Recarregue no navegador (Ctrl+Shift+Del)


   OPÇÃO B: Debugar com Console
   
   1. Pressione F12
   2. Vá para "Console"
   3. Clique em "Salvar"
   4. Procure por:
      - Erros vermelhos
      - "Status: XXX"
      - "Resposta:"
   5. Copie tudo
   6. Compartilhe comigo


   OPÇÃO C: Verificar Banco Manualmente
   
   ssh seu_usuario@seu_servidor
   
   mysql -u usuario -p banco_dados
   
   # Verificar coluna
   DESC users;
   # Procure: professor_id
   
   # Verificar vinculação
   SELECT id, name, role, professor_id FROM users WHERE role = 'teacher' LIMIT 1;
   
   # Vínicular se necessário
   UPDATE users SET professor_id = 1 WHERE id = 1;
   
   exit;
